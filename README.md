# مصاريفي

تطبيق صغير لمصاريفك اليومية. بتكتب أو بتقول اللي صرفته («شربت قهوة بـ 20»)، فبيفهم المبلغ والصنف واليوم، ويحطه تحت بنده. وآخر الشهر تلاقي الإحصائيات والتشارتات.

بيشتغل من غير نت، وبيتنزل على الموبايل زي أي أبلكيشن، وبياناتك على جهازك بس.

## الرفع على GitHub Pages

1. على GitHub اعمل repo جديد (مثلًا `masarefy`)، ويبقى **Public** عشان GitHub Pages المجاني بيشتغل على الـ public بس.
2. ارفع كل الملفات اللي في الفولدر ده للـ repo زي ما هي (`index.html` لازم يبقى في أول الـ repo مش جوه فولدر):
   - من الموقع: **Add file ← Upload files**، واسحب الملفات والفولدرات، وبعدين **Commit changes**.
   - أو من الكمبيوتر:
     ```bash
     cd masarefy
     git init
     git add .
     git commit -m "مصاريفي"
     git branch -M main
     git remote add origin git@github.com:MhammedOsama/masarefy.git
     git push -u origin main
     ```
3. في الـ repo: **Settings ← Pages**. في **Source** اختار **Deploy from a branch**، والـ branch `main` والفولدر `/ (root)`، واضغط **Save**.
4. استنى دقيقة أو اتنين، والتطبيق هيبقى على: `https://mhammedosama.github.io/masarefy/`

أي تعديل تعمله push، بيوصل للموبايل أول ما تفتح التطبيق وانت متوصل بالنت.

## التنزيل على الموبايل

- **أندرويد (Chrome):** افتح اللينك ← التلات نقط ← **Install app** أو **Add to Home screen**.
- **آيفون (Safari):** افتح اللينك ← زرار المشاركة ← **Add to Home Screen**.

## التسجيل بالصوت

- دوس على المايك وقول اللي صرفته، حتى لو أكتر من حاجة: «امبارح ركبت أوبر بـ 85 وشربت قهوة بـ 40».
- أول ما تسكت بيتسجل لوحده، ويطلعلك «تراجع» لو حاجة غلط. وتقدر تدوس «سجّل» وانت لسه بتتكلم.
- تقدر تقفل التسجيل اللوحده من الإعدادات، وساعتها هتدوس «سجّل» بنفسك.
- التسجيل بالصوت بيشتغل كويس على Chrome (أندرويد والكمبيوتر). لو المتصفح مش بيدعمه، استخدم المايك اللي في الكيبورد.

## الفواتير الشهرية

حاجة بتدفعها كل شهر في معاد ثابت، زي الإيجار والنت والكهربا والأقساط والاشتراكات.

- **إضافة:** من تاب «الفواتير» ← «فاتورة جديدة»، أو قولها أو اكتبها في «النهارده»:
  - «فاتورة النت 450 كل شهر يوم 2»
  - «الإيجار 3500 أول كل شهر»
  - «فاتورة الكهربا كل شهر يوم 10»: من غير مبلغ، فبتبقى فاتورة مبلغها بيتغير، والتطبيق بيسألك عليه وانت بتدفع.
  - «نتفليكس 120 شهري»
- **الدفع:** دوس «دفعتها» جنب الفاتورة، أو قول «دفعت فاتورة الكهربا 650». بتتسجل في المصاريف وتختفي من التنبيه لحد الشهر الجاي.
- **التنبيه جوه التطبيق:** لو فيه فاتورة معادها قرب أو النهارده أو اتأخرت، بتظهر فوق في «النهارده»، ورقمها بيظهر على تاب الفواتير (وعلى أيقونة التطبيق في الموبايلات اللي بتدعم ده).
- **الإشعار على الموبايل:** من «الفواتير» ← «حطهم»، أو من جوه الفاتورة ← «حطها في تقويم الموبايل»:
  - **آيفون أو سامسونج:** «نزّل ملف التقويم» وافتحه، وهيسألك تضيف المواعيد. كل فاتورة بتتكرر كل شهر في المعاد والساعة اللي اخترتهم، والتقويم هو اللي بيبعت الإشعار حتى لو التطبيق مقفول.
  - **Google Calendar:** دوس على اسم الفاتورة، وهتفتح صفحة الحدث، ودوس «Save». وقت التنبيه بيبقى حسب إعدادات التقويم بتاعك.
  - لو غيّرت معاد فاتورة، امسحها من التقويم وحطها تاني.
- الفواتير المدفوعة بتتسجل في البند اللي اخترته للفاتورة. الافتراضي «التزامات › فواتير شهرية»، والأقساط في «التزامات › أقساط».

## الاختصار (من غير ما تفتح التطبيق)

أي لينك بالشكل ده بيسجل المصروف على طول:

```
https://mhammedosama.github.io/masarefy/?add=قهوة 20
```

- **آيفون (Siri):** في تطبيق Shortcuts اعمل اختصار فيه «Dictate Text»، وبعده «URL» فيه اللينك وبعده «Dictated Text»، وبعدهم «Open URLs». سمّيه «مصروف»، وقول لـ Siri «مصروف» واتكلم.
- **أندرويد:** دوسة طويلة على أيقونة التطبيق ← «سجّل مصروف» بيفتح التسجيل بالصوت.

ولو حط حاجة في البند الغلط، دوس على البند واختار الصح، وهو بيفتكر الكلمة للمرة الجاية.

## البيانات

- كل حاجة متسجلة في المتصفح على الجهاز ده (localStorage)، ومش بتتبعت لأي حد.
- لو مسحت بيانات المتصفح أو غيّرت الموبايل، البيانات بتضيع. فمن **الإعدادات ← نسخة احتياطية** نزّل ملف كل فترة، أو انسخ الكود وابعته لنفسك على واتساب.
- من نفس المكان تقدر تنزّل كل المصاريف ملف يتفتح في Excel.

## الملفات

| الملف | فيه إيه |
|---|---|
| `index.html` | الصفحة |
| `style.css` | الشكل (فاتح وغامق) |
| `app.js` | الشاشات والبيانات |
| `parser.js` | فهم الكلام والبنود الافتراضية |
| `icons.js` | الأيقونات (من Lucide) |
| `sw.js` | بيخلي التطبيق يفتح من غير نت |
| `manifest.webmanifest` | اسم التطبيق وأيقونته على الموبايل |
| `tests/parser.test.js` | تست لفهم الكلام: `node tests/parser.test.js` |
| `tests/cycle_test.py` | دورة استخدام كاملة يوم بيوم، وكل رقم بيتقارن بدفتر منفصل |
| `tests/quality_test.py` | المقاسات وأسماء الأزرار والسرعة مع سنة بيانات ومن غير نت |
| `tests/REPORT.md` | آخر نتيجة للتست وإزاي تشغّله |

لو عدّلت أي ملف، غيّر `VERSION` في `sw.js` عشان الموبايلات تاخد النسخة الجديدة حتى لو فتحت من غير نت.
